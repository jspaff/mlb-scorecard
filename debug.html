⚾ AB Debug Tool

Look up a catalog of values

MLB publishes complete, authoritative lookup tables for its coded fields — event types, pitch types, positions, review reasons, stat groups, game status, sky/wind conditions, and more — at /v1/<type>. Pick one to see every value it can take, straight from the source.

Show today's game statuses

Lists every game's abstractGameState + detailedState straight from the schedule endpoint. Useful for catching the exact detailedState strings during Pre-Game/Warmup/Delayed Start, and exactly when abstractGameState flips to Live relative to those.

Inspect a play's API values

Pick a game, then a play, to see every field the live feed reports for that at-bat — no need to already know a JSON path. Handy for answering "what does this field actually look like on a real play" for anything that doesn't have a clean catalog above.
